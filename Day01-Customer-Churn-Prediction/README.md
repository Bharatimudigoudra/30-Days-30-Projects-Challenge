# Cutomer Churn Prediction

Cutomer Churn Prediction using python and machine learning. Then we are created one interactive web application using Flask and FastAPI

**The real-world business problem**
Imagine you are working as a Data Scientist for a telecom company.

The company has thousands or millions of customers.

Every month, some customers:

1. cancel their subscription,
2. stop using the company's services,
3. move to a competitor,
4. or simply don't renew.

This is called customer churn.

The company's problem is: “We know some customers are leaving, but can we identify which customers are likely to leave before they actually leave?”
That's where Machine Learning comes in.

**Goal**
The objective was to predict whether a telecom customer was likely to churn based on their demographic information, subscribed services, account details, tenure, contract type, and billing information. We treated it as a binary classification problem, where the target was whether the customer churned or stayed. The business goal was to identify high-risk customers early so that targeted retention strategies could be applied to reduce churn and potential revenue loss.
